# Panini B2B Catalog

A B2B catalog platform for Panini Jewels — built to complement the existing WhatsApp-based sales channel by giving resellers and retailers a shareable, browsable, always-up-to-date catalog.

This project is being built as part of an IT industry re-entry effort — using real product work at Panini Jewels to rebuild interview-ready depth in modern frontend/full-stack development.

Every product decision, technical choice, and trade-off is being documented as it's made. The same documents serve double duty as:
1. Real engineering artifacts for the project
