# Interview Prep — Q&A Bank

A growing collection of interview questions and answers, organized by topic. Every answer is grounded in **real decisions made on the Panini B2B project** — so when you tell these stories in interviews, you're not reciting theory, you're describing what you actually did.

## How to use this folder

1. **Read each topic file** as we add new sections to the project. The Q&A entries reference real artifacts in this repo.
2. **Practice out loud, not just in your head.** Reading silently feels easy; speaking is where you trip up.
3. **Pair each answer with the actual document.** Interviewers love when candidates say *"I can show you the actual brief I wrote — would that help?"*
4. **Update as the project evolves.** When we make a new technical decision (e.g., picking a database, choosing a framework), add the question + your answer here immediately while the reasoning is fresh.

## How questions are formatted

Each entry follows this template:

```markdown
### Q: <The interview question>

**Why this gets asked:**
What the interviewer is testing for.

**Short answer (30 sec):**
A tight, confident response.

**Long answer (2-3 min):**
The full version with detail and examples.

**Story to tell from this project:**
A specific anecdote from Panini B2B that illustrates the answer.

**What NOT to say:**
Common mistakes that signal junior thinking.

**Follow-up questions to expect:**
What the interviewer might dig into next.
```

This format is deliberate — it forces you to think through different conversation lengths and depths. Interviewers ask the same question in different ways depending on time and seniority bar.

## Pro tip for using this in actual interviews

When asked any question, mentally answer in this order:

1. **The principle** — what's the general approach?
2. **The example** — what did you do specifically?
3. **The trade-off** — what did you NOT do, and why?

Senior candidates always include #3. Junior candidates skip it.
